Java DSA Scenarios

This project contains three beginner-friendly Java programs based on real-life scenarios.

Programs

1. ArrayProgram.java — Library Bookshelf
   
   - Add, display, search, update, and delete book IDs.
   - Uses a one-dimensional integer array.

2. StackProgram.java — Stack of Books
   
   - Push, pop, peek, and display operations.
   - Follows LIFO (Last In, First Out).

3. QueueProgram.java — College Canteen Line
   
   - Enqueue, dequeue, peek, and display operations.
   - Follows FIFO (First In, First Out).

Concepts Used

- Java
- Integer arrays
- While loops
- Functions (methods)
- Menu-driven programs

How to Run

Compile and run each program separately using the Java compiler.

Example:

javac ArrayProgram.java
java ArrayProgram

Replace "ArrayProgram" with "StackProgram" or "QueueProgram" to run the other programs.

Purpose

Created for learning and practicing basic Data Structures and Algorithms (DSA) in Java.
